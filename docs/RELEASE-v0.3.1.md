Каждый архив — около 600 МБ. Whisper Small и модели разделения голосов уже в комплекте. Интернет, Python, отдельный FFmpeg, подписка и API-ключи для обработки не нужны.

### Что умеет

- Превращает аудио и видео со звуком в диалог с таймкодами.
- Разделяет обычную запись по голосам; для записи с отдельными каналами есть режим «Два канала».
- Позволяет задать имена и роли участников, прочитать и скопировать разговор в приложении.
- Сохраняет TXT, SRT и JSON в отдельную папку для каждой записи.
- Обрабатывает очередь файлов до 90 минут каждый. Работает на CPU, без сетевых запросов и телеметрии.

### Первый запуск

**Windows:** распакуйте архив полностью и запустите `Ushastik.exe`. Папка `_internal` должна оставаться рядом. Программа без сертификата издателя; Windows может показать предупреждение SmartScreen.

**Mac:** скачайте архив для своего процессора, распакуйте и перенесите `Ушастик.app` в «Программы». Требуется macOS 15+. Подпись ad-hoc, без Developer ID и нотариализации Apple. Если первый запуск заблокирован, после попытки открытия используйте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». [Инструкция Apple](https://support.apple.com/en-us/102445).

### Проверка и точность

Обе Mac-сборки прошли нативную приёмку, включая запуск готового обработчика с сетевым запретом на уровне ОС. На Windows проверены упакованное приложение и расшифровка двумя голосами. Пройдены 30 модульных тестов. [Подробности и границы проверки](https://github.com/kurzemnek/ushastik/blob/v0.3.1/docs/VERIFICATION.md).

Имена участников задаёт человек. Шум, перебивания и короткие реплики могут ухудшать результат; важные формулировки сверяйте со звуком. Испытания использовали синтетические русские диалоги; точность на реальных звонках UIS/CoMagic отдельно не измерена.

Контрольные суммы архивов — в **SHA256SUMS.txt**. Лицензии компонентов включены в каждый архив; исходники нативных медиа-компонентов доступны отдельным архивом **ThirdParty-Sources-0.3.1.zip**. Собственный код Ушастика — MIT.
