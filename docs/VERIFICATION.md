# Проверка выпуска 0.3.1

Проверено 5 ноября 2026 года. Приложение использует локальные модели на CPU.
Тестовые записи — синтетическая русская речь, без клиентских разговоров.

| Платформа | Что проверено |
| --- | --- |
| Windows x64 | Запуск упакованного приложения, уведомление при первом запуске и сохранение подтверждения, расшифровка двумя голосами, TXT/SRT/JSON. |
| macOS 15.8.2, Apple Silicon | Нативная сборка arm64, обработчик из готовой `.app`, локальные модели, голоса, общий текст, два канала, тишина, продолжение после повреждённого файла. |
| macOS 15.7.9, Intel | Те же проверки нативной сборки x86_64. |
| Обе Mac-сборки | Подпись `codesign --verify --deep --strict` до упаковки и после распаковки через `ditto`, исполняемые права, символические ссылки и SHA-256 моделей. |

## Работа без сети

На Mac обработчик из готовой `.app` запускался через `sandbox-exec` с правилом
`(deny network*)`. Контрольное соединение с локальным сервером без ограничений
проходило, а в этом профиле завершалось `EPERM`. Расшифровка внутри профиля прошла.

На Windows использовались пустой кэш Hugging Face, офлайн-флаги и недоступный
прокси. Сеть на уровне ОС в Windows-прогоне не блокировалась.

## Интерфейс

На Mac подробная автоматизация выполнялась с исходным Tk-интерфейсом и
обработчиком из готовой `.app`: уведомление, «О программе», имена участников,
копирование, остановка и повтор, обработчики открытия файлов и завершения.
Отдельно проверены запуск упакованной `.app` и завершение через AppleEvent.
Проверены маленький экран 1024×768 и расположение элементов выше Dock.
Регистрация и вызов обработчика перетаскивания проверены программно.

Скриншот в README показывает интерфейс версии 0.3.1 и результат ранее
проверенной расшифровки синтетического диалога. Имена участников заданы вручную.

## Исходники и упаковка

Нативная Mac-приёмка выполнена на коммите
[`1426233`](https://github.com/kurzemnek/ushastik/commit/14262331770d43efcb76f07d0f3e53323a60a201):
[запуск GitHub Actions](https://github.com/kurzemnek/ushastik/actions/runs/42071693264),
тег `macos-v0.3.1`. Публикационный тег `v0.3.1` дополнительно содержит
документацию, оформление, комплект лицензий и сценарии их упаковки.

Windows-сборка 0.3.1 подготовлена до последующих изменений интерфейса для Mac.
После этих изменений выполнена регрессионная проверка Windows-интерфейса.

Перед публикацией к проверенным архивам добавлены инструкции и лицензии
компонентов. Они лежат **вне подписанной `.app`**. Файлы приложения, модели,
Unix-права и содержимое символических ссылок сверены с исходными архивами.
В Windows обновлён текст инструкции. Контрольные суммы итоговых архивов
опубликованы в `SHA256SUMS.txt` на странице релиза.

## Границы проверки

- Mac-сборки рассчитаны на macOS 15+. Более ранние системы не проверялись.
- Подпись Mac — ad-hoc, без Developer ID и нотариализации Apple. Первый запуск
  загруженного архива с Gatekeeper на пользовательском Mac отдельно не проверен.
- Windows-программа не подписана сертификатом издателя.
- Полный ручной прогон мышью и физическое перетаскивание на обоих Mac не проводились.
- Качество на реальных шумных звонках UIS/CoMagic не измерено. Перебивания,
  похожие голоса и короткие реплики могут ухудшать результат.

30 модульных тестов проверяют границы обработки, объединение слов и привязку
говорящих. Эти проверки и нативная приёмка подтверждают работоспособность
проверенных сценариев, а не безошибочное распознавание любой записи.
